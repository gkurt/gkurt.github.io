Scrollbar-stable padding

Classic scrollbars shift content 11px to the left when they appear.scrollbar-gutter: stable fixes the shift by always reserving the gutter — but that wastes space when no scrolling is needed.

The trick: use @container scroll-state() on the scroller to detect when it's actually scrollable, and shave 11px off the right padding only in that state.

Requires container-type: scroll-state (Chromium 133+, Safari 26+).

Inboxright edge →
    .scroller {
  overflow-y: auto;
  /* no stabilization — content shifts when scrollbar appears */
}

.list {
  padding: 16px;
}
    .scroller {
  overflow-y: auto;
  scrollbar-gutter: stable;
  /* always reserves 11px even when not scrollable */
}

.list {
  padding: 16px;
}
    .scroller {
  overflow-y: auto;
  container-type: scroll-state;
}

.list {
  padding: 16px;
}

/* The trick: when the scroller can move (either direction),
   shave 11px off padding-right so total visual right space
   matches the un-scrollable state. */
@container scroll-state((scrollable: top) or (scrollable: bottom)) {
  .list {
    padding-right: 5px;
  }
}
