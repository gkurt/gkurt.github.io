CSS mechanism · anchor positioning

Geometry without polling

CSS anchor positioning can hand one element another element's box ascomputed lengths. Computed lengths take part in transitions. Transitions fire DOM events. Chain those three facts together and the layout engine will tell you, unprompted, every time an element moves or resizes — no requestAnimationFrame loop, no observer re-arming, no main-thread work at all while nothing changes.

The pipeline

Every existing answer to “tell me when this element moved” is a sampler. ResizeObserver sees size but never position.IntersectionObserver must be torn down and rebuilt around the element's current rect after every single hit. Everything else is arequestAnimationFrame loop calling getBoundingClientRect()sixty times a second forever, mostly to learn that nothing happened.

The trick here is to stop asking, and instead make the browser's own style machinery carry the answer out to you. It takes three hops, and each one is an ordinary, shipped CSS feature.

  1. 01

    Geometry becomes style

    anchor() and anchor-size() resolve another element's box into real lengths on this element. The engine keeps them in sync as part of layout — that's the whole point of the feature.

  2. 02

    Style becomes a transition

    Those lengths are ordinary computed values, so they are transitionable. Give the mirror a 1ms transition and any change to the source element's box starts a transition on the mirror.

  3. 03

    The transition becomes an event

    A running transition dispatches transitionrun. That is the notification. It arrives only when geometry actually changed, and it costs nothing when it doesn't.

/* The probe: a top-layer element that mirrors #target's box. */
#probe {
  position: fixed;
  position-anchor: --target;        /* default anchor -> engine keeps it glued, */
                                    /* scroll adjustment included               */
  top:    anchor(top);
  left:   anchor(left);
  width:  anchor-size(width);
  height: anchor-size(height);

  transition: top 1ms, left 1ms, width 1ms, height 1ms;  /* the tap */
}

Two details do a lot of work. position-anchor (rather than naming the anchor inside each anchor() call) establishes adefault anchor, which is what makes the engine apply scroll adjustment — with it, probe.getBoundingClientRect() returns the target's true viewport rect even when the target sits inside a nested scroller. And popover="manual" puts the probe in the top layer, so no ancestor's overflow: hidden, transform,filter or contain can clip it or hijack its containing block.

03  Detection with no JavaScript at all

Once geometry is a length, it can drive a container query — and container queries change style, and style changes fire transitions. So the detection path can be pure CSS end to end, with script present only to write a log line.

04  What it costs

Honest accounting, measured on your machine right now. Probes are not free: each one is a real box the engine lays out, so they add time to every reflow — including reflows in which nothing they watch actually moved, which is why the table measures that case separately from the one where everything moves. What they buy is that a sampler pays on all sixty frames a second whether or not anything moved, and probes pay nothing at all.

Two recipe changes do most of the work. content-visibility: hiddencosts the probe nothing — it has no contents to skip — and takes a sizeable bite out of its share of a reflow. Narrowing track to just position or just size transitions two properties instead of four, and on a busy page that is the bigger lever of the two. How much each is worth depends on what else the page is laying out, so the table measures it here rather than quoting a figure from somewhere else.

05  The cases that used to be blind spots

Two gaps were left open: scrolling, and a transform animating on some ancestor. The second one turned out not to be a limitation of the technique at all — it was a limitation of where the probe lived. A probe parked inside the transformed subtree moves along with its target, so the insets never change and nothing fires. Put the probe in thetop layer and its containing block is the viewport, outside whatever is being transformed — so the anchor-resolved insets really do change, and the events really do fire. That holds for awill-change: transform ancestor, and for transforms on<body> and <html> too.

Scrolling still doesn't fire, and can't: Chromium applies anchor scroll adjustment after layout by design, which is exactly why the probe's rect stays correct for free. So scroll is handled by one passive capture-phase listener, routed by scroller.contains(target) so that scrolling one pane never wakes observers watching another.

The third gap was teardown. Hiding the target with display: none, or detaching it, invalidates the anchor — and an invalid anchor function is invalid at computed-value time, so the property falls back to auto. A length does not interpolate to auto, so no transition runs and the element's disappearance is never announced. Measured over repeated trials:0 of 4 detachments reported, 0 of 4 hides.

The fix is one argument. anchor(top, -99999px) andanchor-size(width, 0px) give the function a fallback, so losing the anchor leaves a length rather than auto — the value stays interpolable, the transition runs, and the probe announces its own orphaning by parking off-screen. 4 of 4 for both cases with the fallback in place. Entries then carry a state of rendered,hidden or detached, because 0×0 is not the same fact as “hidden” or “gone” — ResizeObserver reports all three identically. A detached target is reported once and then released.

Caveats worth knowing

  • Chromium only, for now

    Anchor positioning shipped in Chromium 125. Firefox and Safari are implementing it but haven't shipped. Feature-detect with CSS.supports('anchor-name','--x') and fall back to a shared rAF sampler.

  • Scrolling doesn't fire

    Chromium applies anchor scroll adjustment after layout, so scrolling moves the probe without changing its computed insets — the rect stays correct, but no transition runs. One passive capture-phase scroll listener completes the coverage, routed by contains() so an unrelated pane's scrolling costs nothing.

  • Keep the probe out of the subtree

    Ancestor transforms only register because the top-layer probe's containing block is the viewport. A probe that is merely position: fixed inside a transformed ancestor is carried along by it and reports nothing — which is the trap the first version of this page fell into. If showPopover() is unavailable, expect that blind spot back.

  • Composited transforms trail by half a frame

    Mid-animation the anchor resolves against the previous frame's transform, so a probe-driven overlay sits a few pixels behind a fast-moving target. It is exact the moment the animation settles. For overlays that must be pixel-locked during motion, put them in the same transformed subtree and let the compositor carry them.

  • Tree order is load-bearing — unless the probe is fixed

    An absolutely positioned element can only anchor to something that precedes it in tree order; point one at a later sibling and its insets silently resolve to nothing. That is what broke the gauges in demo 02 the first time. A position: fixed probe takes the viewport as its containing block and is immune — it resolves anchors for targets that do not exist yet — so the observer never has to care where in the document its probes land.

  • Narrowing track narrows reporting, not measuring

    Switching to track: 'size' stops a pure move from raising an event, because only width and height are left with a transition on them. It does not make positions stale: every entry carries the target's live rect, so the next report from any cause brings a fully current x and y with it — measured, a resize after an untracked move reported the new position exactly. What you give up is the moment of a move, not the knowledge of one.

  • Settling is trailing-edge only

    Because settle is a transition-delay, every change cancels the pending transition and restarts the wait — measured over 30 frames of continuous movement, 28 events become 0, then exactly one lands a delay's width after the last change. A JS debounce cannot match that: it has to run on every frame to reset its own timer, so the main thread never gets to stay quiet. The edge to know about is the other side of the same coin: a target that never stops moving never reports at all. Scroll and viewport wakes have no transition behind them, so those honour settle with a real timer instead.

  • Scroll-driven animations can't carry this

    The obvious thought is to let a scroll() or view() timeline report scrolling instead of a listener. They do fire finish as a range is crossed, and re-arm themselves on the way back, which makes a view() tripwire a genuinely good way to be told about chosen positions. But a scroll-driven animation never starts a transition — animations outrank transitions in the cascade — so the timeline cannot feed the mechanism on this page. Routing its value through an animated container width and a @container rule does close the loop, at the price of a relayout on every scrolled frame. A passive listener that costs nothing until it fires wins.

  • A CSS reset can switch it off silently

    The 1ms transition is the mechanism, not decoration, so a blanket * { transition: none !important } — which plenty of reduced-motion and test setups ship — stops every event while the probe carries on tracking its target perfectly. The observer writes its probe declarations with !important in the style attribute, which outranks an important rule in a stylesheet and is the one placement CSS cannot beat. Probes you hand-write in a stylesheet, like the visible ones on this page, have no such protection.

The whole thing

No dependencies, ResizeObserver-shaped API. This is the exact module running the first demo on this page. Passobserve(el, { anchorName: '--my-anchor' }) to reuse a name the page already declares, in which case the target's ownanchor-name is never touched. Entries carrystate, previousRect, moved andresized alongside the rect, and{ settle: 250 } debounces throughtransition-delay rather than a timer. All of that is live:reconfigure({ track, settle }) rewrites one inline declaration per probe, so nothing is torn down, re-observed or re-measured — the settle toggle above is exactly that call. Probes are kept in a singledisplay: contents group, so observing a hundred elements adds one child to <body> rather than a hundred.

/**
 * GeometryObserver — event-based position + size observation.
 *
 * Chains three shipped CSS features into a notification:
 *
 *   1. anchor() / anchor-size() resolve another element's box into computed
 *      lengths on a "probe" element, kept in sync by layout.
 *   2. Those are ordinary computed values, so they are transitionable.
 *   3. A running transition dispatches `transitionrun`.
 *
 * The probe never affects layout, never paints, and runs no JavaScript. It
 * sits there being an exact copy of a box, waiting to complain.
 *
 * Three details are load-bearing:
 *
 *   - `position-anchor` (rather than naming the anchor inside each anchor()
 *     call) establishes a *default anchor*, which is what makes Chromium apply
 *     scroll adjustment — with it the probe's rect is correct even when the
 *     target sits inside a nested scroller.
 *   - `popover="manual"` puts the probe in the top layer. That stops any
 *     ancestor's overflow/transform/filter/contain from clipping it or
 *     stealing its containing block, sidesteps the rule that an element can
 *     only anchor to something preceding it in tree order, and — because the
 *     probe's containing block is then the viewport rather than anything
 *     inside the transformed subtree — is what makes ancestor `transform`
 *     changes show up as events at all.
 *   - `content-visibility: hidden` costs the probe nothing visually and takes a
 *     sizeable bite out of its share of each reflow (measured between 1.5x and
 *     3x depending on how much else the page is laying out).
 *
 * Coverage: every layout-driven move or resize fires, so does every transform
 * on any ancestor (including <body> and <html>), and so does the target being
 * hidden or detached (see the fallbacks in PROBE_STYLE). Scrolling is the one
 * thing that does not — Chromium applies anchor scroll adjustment after
 * layout, so the probe's rect stays correct but no transition runs — which is
 * why there is a routed `scroll` listener below rather than a polling loop.
 */

export type BatchMode = 'frame' | 'sync';
export type Track = 'both' | 'position' | 'size';

export interface GeometryObserverInit {
  /**
   * 'frame' (default) delivers one batched callback per animation frame, like
   * ResizeObserver. 'sync' delivers during the transition event itself — a
   * frame earlier, at the cost of possibly several callbacks per frame.
   */
  batch?: BatchMode;
  /**
   * Narrow what counts as a change. Transitioning two properties instead of
   * four roughly halves the probe's cost. Default 'both'.
   */
  track?: Track;
  /**
   * Report only once the geometry has been still for this many milliseconds.
   *
   * This is `transition-delay`, not a timer. Each new change cancels the
   * pending transition and restarts its delay, so `transitionstart` fires only
   * after things settle — which means that during churn **no event reaches the
   * main thread at all**. A JS debounce cannot do that: it still has to be
   * called on every frame in order to reset its own timer. Measured over 30
   * frames of continuous movement: 28 events undelayed, 0 with a delay set,
   * then exactly one arriving a delay's width after the last change.
   *
   * Trailing edge only, with the sharp edge that implies: a target that never
   * stops moving never reports. Default 0 (report every change).
   */
  settle?: number;
}

export interface ObserveOptions {
  /**
   * Reuse an anchor name the page already declares (`--tooltip-anchor`, say)
   * instead of minting one. When given, the target's own `anchor-name` is left
   * completely untouched — nothing is written to its style attribute and
   * nothing has to be restored on unobserve — which also skips the computed
   * style read that attaching otherwise needs.
   */
  anchorName?: string;
}

/**
 * Why a zero rect is not enough: an element collapsed to 0x0 by its own
 * content, one hidden with `display: none`, and one detached from the document
 * all measure the same and mean completely different things to a caller
 * deciding whether to keep an overlay alive.
 */
export type GeometryState =
  /** In the document and generating boxes. The rect means what it says. */
  | 'rendered'
  /** Still in the document but generating no boxes (`display: none` or inside
   *  something that is). The rect is zeroed and carries no information. */
  | 'hidden'
  /** No longer in the document. Reported once, then the target is released. */
  | 'detached';

export interface GeometryEntry {
  readonly target: Element;
  readonly rect: DOMRectReadOnly;
  readonly previousRect: DOMRectReadOnly | null;
  readonly moved: boolean;
  readonly resized: boolean;
  readonly state: GeometryState;
}

export type GeometryCallback = (entries: GeometryEntry[], observer: GeometryObserver) => void;

/** Whether this engine can run the mechanism, or has to fall back to sampling. */
let supported: boolean | undefined;
export function isSupported(): boolean {
  supported ??=
    typeof CSS !== 'undefined' &&
    CSS.supports('anchor-name', '--x') &&
    CSS.supports('top', 'anchor(top)') &&
    CSS.supports('width', 'anchor-size(width)');
  return supported;
}

const TRACKED: Record<Track, readonly string[]> = {
  both: ['top', 'left', 'width', 'height'],
  position: ['top', 'left'],
  size: ['width', 'height'],
};

/**
 * 1ms of duration is all the mechanism needs; the delay is what debounces.
 * We listen for `transitionstart` rather than `transitionrun`, because run
 * fires when the transition is *created* (so once per frame regardless) while
 * start fires when the delay has elapsed. With no delay the two coincide.
 */
function transitionFor(track: Track, settle: number): string {
  return TRACKED[track].map((prop) => `${prop} 1ms ${settle}ms`).join(', ');
}

/**
 * Every probe declaration is written with `!important`. The transition is not
 * decoration here, it is the entire mechanism, and a blanket author reset —
 * `* { transition: none !important }`, which plenty of reduced-motion and test
 * setups ship — otherwise switches the observer off silently: the probe goes
 * on tracking the target perfectly and simply stops reporting. An important
 * declaration in a style attribute outranks an important one in a stylesheet,
 * so this is the only placement that cannot be overridden from CSS.
 */
const PROBE_STYLE: Readonly<Record<string, string>> = {
  position: 'fixed',
  margin: '0',
  border: '0',
  padding: '0',
  background: 'none',
  visibility: 'hidden',
  'pointer-events': 'none',
  'content-visibility': 'hidden',
  // The fallback arguments are what make teardown observable at all. Without
  // them, losing the anchor leaves these properties invalid at computed-value
  // time, so they resolve to `auto` -- and a length does not interpolate to
  // `auto`, so no transition runs and the target's disappearance is never
  // announced. Measured: 0 of 4 detachments and 0 of 4 `display: none`s
  // reported without fallbacks, 4 of 4 of each with them. The value stays a
  // length, the transition runs, and the probe parks itself far off-screen.
  top: 'anchor(top, -99999px)',
  left: 'anchor(left, -99999px)',
  width: 'anchor-size(width, 0px)',
  height: 'anchor-size(height, 0px)',
};

interface Watch {
  probe: HTMLElement | null;
  /** Empty when the caller supplied the anchor name, so we never wrote one. */
  priorAnchorName: string;
  ownsAnchorName: boolean;
  /**
   * Whether we have actually written to the target's anchor-name yet. Attach
   * is deferred to a microtask, so an observe() followed by a synchronous
   * unobserve() -- a fast mount/unmount, say -- must leave the target exactly
   * as it found it rather than removing a name the page set itself.
   */
  wroteAnchorName: boolean;
  last: DOMRectReadOnly | null;
  key: string;
}

/* ------------------------------------------------------------------ *
 * Shared infrastructure — one set of listeners and one fallback loop
 * for every observer on the page, rather than one per instance.
 * ------------------------------------------------------------------ */

const live = new Set<GeometryObserver>();
let listening = false;
let samplerTick = 0;

function onScroll(event: Event): void {
  const scroller = event.target;
  for (const observer of live) observer.wakeWithin(scroller);
}
function onViewportChange(): void {
  for (const observer of live) observer.wakeAll();
}

function enlist(observer: GeometryObserver): void {
  live.add(observer);
  if (!listening) {
    listening = true;
    addEventListener('scroll', onScroll, { capture: true, passive: true });
    addEventListener('resize', onViewportChange, { passive: true });
    visualViewport?.addEventListener('resize', onViewportChange, { passive: true });
    visualViewport?.addEventListener('scroll', onViewportChange, { passive: true });
  }
  // Without anchor positioning there is nothing to listen to, so this is the
  // one path that samples. One shared loop serves every observer.
  if (!isSupported() && !samplerTick) {
    const loop = () => {
      samplerTick = requestAnimationFrame(loop);
      for (const observer of live) observer.wakeAll();
    };
    samplerTick = requestAnimationFrame(loop);
  }
}

function delist(observer: GeometryObserver): void {
  live.delete(observer);
  if (live.size) return;
  listening = false;
  removeEventListener('scroll', onScroll, { capture: true });
  removeEventListener('resize', onViewportChange);
  visualViewport?.removeEventListener('resize', onViewportChange);
  visualViewport?.removeEventListener('scroll', onViewportChange);
  if (samplerTick) cancelAnimationFrame(samplerTick);
  samplerTick = 0;
  releaseProbeGroup();
}

/**
 * Every probe lives inside one `display: contents` group rather than as a
 * direct child of <body>. The host page's body then gains a single child
 * instead of one per observed element, so `body.children`, `body > *` rules,
 * `:nth-child()` and anything walking the top of the document still see what
 * the page author actually put there. `display: contents` means the group
 * generates no box at all, so it can neither affect layout nor become a
 * containing block; and because the probes sit in the top layer, even a page
 * rule that forces a transform onto the group leaves them anchored correctly.
 */
let group: HTMLElement | null = null;

function probeGroup(): HTMLElement {
  if (group?.isConnected) return group;
  group = document.createElement('div');
  group.dataset.geometryProbes = '';
  group.setAttribute('aria-hidden', 'true');
  group.style.setProperty('display', 'contents', 'important');
  document.body.append(group);
  return group;
}

function releaseProbeGroup(): void {
  if (group && !group.childElementCount) {
    group.remove();
    group = null;
  }
}

/** Probes are interchangeable, so retire them to a pool instead of churning DOM. */
const pool: HTMLElement[] = [];
let seq = 0;

function takeProbe(): HTMLElement {
  const probe = pool.pop();
  if (probe) return probe;
  const el = document.createElement('div');
  el.setAttribute('popover', 'manual');
  el.dataset.geometryProbe = '';
  return el;
}

function retireProbe(probe: HTMLElement): void {
  try {
    probe.hidePopover();
  } catch {
    /* never shown */
  }
  probe.remove();
  probe.style.cssText = '';
  if (pool.length < 64) pool.push(probe);
}

export class GeometryObserver {
  #cb: GeometryCallback;
  #batch: BatchMode;
  #track: Track;
  #settle: number;
  #settleTimer = 0;
  #watches = new Map<Element, Watch>();
  #pendingObserve: { target: Element; anchorName?: string }[] = [];
  #dirty = new Set<Element>();
  #records: GeometryEntry[] = [];
  #tick = 0;
  #queued = false;

  constructor(callback: GeometryCallback, init: GeometryObserverInit = {}) {
    this.#cb = callback;
    this.#batch = init.batch ?? 'frame';
    this.#track = init.track ?? 'both';
    this.#settle = Math.max(0, init.settle ?? 0);
  }

  get track(): Track {
    return this.#track;
  }
  get settle(): number {
    return this.#settle;
  }
  get batch(): BatchMode {
    return this.#batch;
  }

  /**
   * Change what counts as a change, without tearing anything down.
   *
   * `track` and `settle` live entirely in one inline `transition` declaration
   * on each probe, so switching them is a style write per observed element --
   * no probe is rebuilt, no anchor-name is touched, and no target is
   * re-measured. Targets queued by `observe()` but not yet attached pick the
   * new values up on their own, since attachment reads them when it runs.
   *
   * Narrowing `track` means the narrowed-away axis stops *reporting*, not that
   * it stops being measured: entries always carry the full rect, so after
   * switching to `'size'` a position is still accurate whenever something else
   * causes a report, but a pure move no longer causes one.
   */
  reconfigure(init: GeometryObserverInit): void {
    if (init.batch !== undefined) this.#batch = init.batch;
    const retune = init.track !== undefined || init.settle !== undefined;
    if (init.track !== undefined) this.#track = init.track;
    if (init.settle !== undefined) this.#settle = Math.max(0, init.settle);
    if (!retune) return;

    const transition = transitionFor(this.#track, this.#settle);
    for (const watch of this.#watches.values()) {
      watch.probe?.style.setProperty('transition', transition, 'important');
    }
    // Dropping the delay while a wake was still waiting it out would otherwise
    // leave that change sitting in the timer for the old duration.
    if (!this.#settle && this.#settleTimer) {
      window.clearTimeout(this.#settleTimer);
      this.#settleTimer = 0;
      this.#schedule();
    }
  }

  observe(target: Element, options: ObserveOptions = {}): void {
    if (this.#watches.has(target)) return;
    const { anchorName } = options;
    if (anchorName !== undefined && !anchorName.startsWith('--')) {
      throw new TypeError(`anchorName must be a dashed ident, got "${anchorName}"`);
    }
    // Placeholder so a second observe() in the same tick is a no-op.
    this.#watches.set(target, {
      probe: null,
      priorAnchorName: '',
      ownsAnchorName: anchorName === undefined,
      wroteAnchorName: false,
      last: null,
      key: '',
    });
    this.#pendingObserve.push({ target, anchorName });
    if (this.#pendingObserve.length === 1) queueMicrotask(() => this.#attachPending());
    enlist(this);
  }

  unobserve(target: Element): void {
    const watch = this.#watches.get(target);
    if (!watch) return;
    if (watch.probe) retireProbe(watch.probe);
    if (watch.ownsAnchorName && watch.wroteAnchorName) {
      // anchor-name may have been the page's own; put back exactly what was there.
      const style = (target as HTMLElement).style;
      if (watch.priorAnchorName) style.setProperty('anchor-name', watch.priorAnchorName);
      else style.removeProperty('anchor-name');
    }
    this.#watches.delete(target);
    this.#dirty.delete(target);
    if (!this.#watches.size) delist(this);
  }

  disconnect(): void {
    for (const target of [...this.#watches.keys()]) this.unobserve(target);
    this.#pendingObserve.length = 0;
    this.#records.length = 0;
    if (this.#tick) cancelAnimationFrame(this.#tick);
    this.#tick = 0;
    window.clearTimeout(this.#settleTimer);
    this.#settleTimer = 0;
    delist(this);
  }

  /** Pending entries, cleared. Mirrors ResizeObserver.takeRecords(). */
  takeRecords(): GeometryEntry[] {
    this.#collect();
    return this.#records.splice(0);
  }

  /** @internal — a scroller moved; only elements inside it can have shifted. */
  wakeWithin(scroller: EventTarget | null): void {
    if (!this.#watches.size) return;
    const root = scroller instanceof Element ? scroller : null;
    for (const target of this.#watches.keys()) {
      if (!root || root === document.scrollingElement || root.contains(target)) {
        this.#dirty.add(target);
      }
    }
    if (this.#dirty.size) this.#wakeScheduled();
  }

  /** @internal */
  wakeAll(): void {
    for (const target of this.#watches.keys()) this.#dirty.add(target);
    if (this.#dirty.size) this.#wakeScheduled();
  }

  /**
   * Scrolling and viewport resizes reach us as plain events with no transition
   * behind them, so there is no CSS delay to lean on. Honour `settle` here with
   * an actual timer, otherwise the same observer would debounce layout changes
   * and fire immediately on scroll.
   */
  #wakeScheduled(): void {
    if (!this.#settle) {
      this.#schedule();
      return;
    }
    window.clearTimeout(this.#settleTimer);
    this.#settleTimer = window.setTimeout(() => {
      this.#settleTimer = 0;
      this.#schedule();
    }, this.#settle);
  }

  /**
   * Attach every target queued this tick. Reading all the prior anchor-names
   * before writing any keeps this to a single style flush instead of one per
   * target, which matters when a page observes a few hundred elements at once.
   */
  #attachPending(): void {
    const pending = this.#pendingObserve.splice(0);
    if (!pending.length) return;

    // Read every prior anchor-name before writing any, so a bulk observe costs
    // one style flush rather than one per target. Caller-supplied names need no
    // read at all, since we leave those targets alone.
    const priors = pending.map(({ target, anchorName }) =>
      anchorName !== undefined || !isSupported()
        ? { inline: '', computed: '' }
        : {
            inline: (target as HTMLElement).style.getPropertyValue('anchor-name'),
            computed: getComputedStyle(target).getPropertyValue('anchor-name').trim(),
          },
    );

    pending.forEach(({ target, anchorName }, i) => {
      const watch = this.#watches.get(target);
      if (!watch) return; // unobserved before we got here
      watch.priorAnchorName = priors[i].inline;

      if (isSupported()) {
        let name: string;
        if (anchorName !== undefined) {
          name = anchorName; // the page owns it; touch nothing
        } else {
          name = `--geo-probe-${++seq}`;
          const prior = priors[i].computed;
          // anchor-name is a list — never clobber a name the page already set.
          (target as HTMLElement).style.setProperty(
            'anchor-name',
            prior && prior !== 'none' ? `${prior}, ${name}` : name,
          );
          watch.wroteAnchorName = true;
        }

        const probe = takeProbe();
        const style = probe.style;
        for (const [prop, value] of Object.entries(PROBE_STYLE)) {
          style.setProperty(prop, value, 'important');
        }
        style.setProperty('position-anchor', name, 'important');
        style.setProperty('transition', transitionFor(this.#track, this.#settle), 'important');
        // position:fixed means the probe's containing block is the viewport, so
        // it resolves anchors regardless of tree order -- including targets that
        // do not exist yet. Where the group sits is placement, not a dependency.
        probeGroup().append(probe);
        try {
          probe.showPopover();
        } catch {
          /* no top layer: still anchors, but loses clip/transform immunity */
        }
        // The CSS delay has already done the waiting by the time this fires,
        // so deliver straight away rather than waiting again in JS.
        probe.addEventListener('transitionstart', () => {
          this.#dirty.add(target);
          this.#schedule();
        });
        watch.probe = probe;
      }

      this.#dirty.add(target);
    });

    this.#schedule();
  }

  #schedule(): void {
    if (this.#batch === 'sync') {
      // Layout is already clean inside a transition event, so reading now is
      // free and lands the callback a frame earlier than rAF would.
      this.#collect();
      this.#deliver();
      return;
    }
    if (this.#tick) return;
    this.#tick = requestAnimationFrame(() => {
      this.#tick = 0;
      this.#collect();
      this.#deliver();
    });
  }

  #collect(): void {
    if (!this.#dirty.size) return;
    for (const target of this.#dirty) {
      const watch = this.#watches.get(target);
      if (!watch) continue;

      // Always measure the target, never the probe. The probe exists to raise
      // the event; its rect is only a mirror, and once its anchor is gone the
      // probe is parked on its fallback and describes nothing. The target's own
      // getBoundingClientRect() is the scroll- and transform-adjusted truth in
      // every state, and honestly reports zeroes in the states below.
      const connected = target.isConnected;
      const rect = target.getBoundingClientRect();
      const state: GeometryState = !connected
        ? 'detached'
        : rect.width > 0 || rect.height > 0 || target.getClientRects().length > 0
          ? 'rendered'
          : 'hidden';

      // State belongs in the dedupe key: an element that was already 0x0 and
      // then gets hidden has the same rect and a different meaning.
      const key = `${state}|${rect.x},${rect.y},${rect.width},${rect.height}`;
      if (key === watch.key) continue; // woken by a scroll with nothing to say
      const previousRect = watch.last;
      watch.key = key;
      watch.last = rect;
      this.#records.push({
        target,
        rect,
        previousRect,
        moved: !previousRect || previousRect.x !== rect.x || previousRect.y !== rect.y,
        resized:
          !previousRect ||
          previousRect.width !== rect.width ||
          previousRect.height !== rect.height,
        state,
      });
      // Nothing more can happen to a detached target, so report it once and
      // let go -- otherwise its probe and anchor-name leak for the page's life.
      if (state === 'detached') this.unobserve(target);
    }
    this.#dirty.clear();
  }

  #deliver(): void {
    if (!this.#records.length || this.#queued) return;
    const entries = this.#records.splice(0);
    this.#queued = true;
    try {
      this.#cb(entries, this);
    } finally {
      this.#queued = false;
    }
  }
}
