Demos

Small experiments and one-off explorations, mostly CSS.

tool/tool/anagram

Anagram checker

Test strings against a source for anagram matches, with look-alike character mapping and dictionary-aware suggestions for solving puzzle games.

css/demo/geometry-observer

Geometry without polling

Anchor positioning mirrors an element's box onto a probe, a 1ms transition turns every change into a DOM event — position and size observation with no rAF loop.

data viz/demo/lotr-startup-names

LOTR entities as startup names

An entirely unscientific scatter chart rating Lord of the Rings entities by their potential as startup brand names.

web api/demo/pointer-lock-scrub

Pointer lock scrubbing

Three scrubbable number inputs — one plain, one that grabs the pointer for the whole drag, and one that only grabs it when the cursor runs out of screen.

physics/demo/elastic-scroll

Elastic scroll

A joke physics page where every card is tethered to the scrollbar thumb — the strings drag you back as you scroll, then snap and drop their cards into the basement.

css/demo/parallax-perspective

Perspective parallax, explained

A scroll-driven walkthrough of CSS-perspective parallax — perspective, preserve-3d and translateZ giving each layer a depth-based scroll speed.

css/demo/parallax-scene

CSS parallax scene

An auto-panning 3D landscape built from a single perspective and one translateZ per depth layer — near scenery sweeps past faster than far.

css/demo/view-transition-blur

View transition motion blur

Two side-by-side view transitions running the same slide — one layers a motion-blur pulse onto the ::view-transition pseudo-elements, the other doesn't.

css/demo/scrollbar-stable

Stable scrollbar padding

Using @container scroll-state to compensate for the scrollbar without reserving an empty gutter.

css/demo/scroll-fade

scroll-fade utilities

Scroll-driven mask gradients applied at the edges of a scroll container, tunable live.

css/demo/border-shape

border-shape weather cards

Clipping layered weather cards with the CSS border-shape property and a text-silhouette outline.

css/demo/gradient-border

Gradient border

A rainbow gradient painted onto a border via border-image, then clipped with border-shape.
