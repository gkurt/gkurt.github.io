## Tegaki

Tegaki is an open-source handwriting animation library and generator for the web: it turns any font into text that writes itself stroke by stroke, in the order a hand would draw it. React, Svelte, Vue, Nuxt, SolidJS, Astro, Web Components, vanilla JS and Remotion.

```sh
npm i tegaki
```
